## ✨ What is Omni Product Studio?

**Omni Product Studio** is a free, open-source AI tool that transforms your ordinary product photos into professional cinematic product shots instantly. Whether you're selling on e-commerce platforms, building a portfolio, or creating marketing materials — Omni Product Studio delivers stunning results in seconds using the power of Google Gemini AI.

- 🎬 **Cinematic Product Shots** — Transform static product images into professional, studio-quality visuals

# 💻 Version 1 — Developer (Run Locally)

> Download the source code, open in VS Code, and run locally. Full code access included.

---

### 📋 Prerequisites — Install These First

#### 1. 🟢 Node.js (v18 or higher)
👉 [**Download Node.js**](https://nodejs.org/en/download) — Choose the **LTS** version

#### 2. 💻 VS Code
👉 [**Download VS Code**](https://code.visualstudio.com/download)

#### 3. 🔑 Google Gemini API Key (Free)
👉 [**Get Free API Key**](https://aistudio.google.com/app/apikey) — Sign in with Google → Click **"Create API Key"**

---

### 🚀 Setup Steps

**Step 1** — Download the project source code:

Click the green **"Code"** button on this page → **"Download ZIP"** → Extract the ZIP file

**Step 2** — Open in VS Code:

Open VS Code → **File** → **Open Folder** → Select the extracted folder

**Step 3** — Open the terminal in VS Code (**Terminal → New Terminal**) and install dependencies:
```bash
npm install
```

**Step 4** — Add your Gemini API Key to the config file:
```javascript
// apikey.js or .env file
GEMINI_API_KEY = "your-gemini-api-key-here"
```

**Step 5** — Start the app:
```bash
npm run dev
```

**Step 6** — Open your browser:
```
http://localhost:5173
```

🎬 Upload your product image and generate cinematic shots instantly!

# ⚡ Version 2 — Direct Install (One-Click Setup)

> Download and install the app directly — no coding required. Just connect your API key and start creating.

---

### 🚀 Setup Steps

**Step 1** — Download the installer:

Go to the **[Releases](../../releases)** page → Download the latest installer for your platform:
- 🪟 **Windows** → `.exe` installer
- 🍎 **Mac** → `.dmg` file
- 🐧 **Linux** → `.AppImage` file

**Step 2** — Install the app:

Double-click the downloaded file and follow the installation steps.

**Step 3** — Get your free Gemini API Key:

👉 Go to [**aistudio.google.com/app/apikey**](https://aistudio.google.com/app/apikey) → Sign in with Google → Click **"Create API Key"** → Copy the key

**Step 4** — Connect your API Key:

Open Omni Product Studio → Click ⚙️ **Settings** → Paste your API key in the **"Gemini API Key"** field → Click **"Save"**

**Step 5** — Start Creating! 🎬

Upload your product photo → Choose a style → Click **"Generate"** → Download your cinematic product shot!

## ❓ FAQ

**Q: Is Omni Product Studio really free?**
> Yes! The app is completely free and open source. You only need a free Google Gemini API key.

**Q: What types of products work best?**
> Any product with a clear subject works great — clothing, electronics, food, cosmetics, accessories, and more.

**Q: Is my uploaded image safe?**
> Your images are processed via Google's Gemini API. Please review Google's [privacy policy](https://policies.google.com/privacy) and [terms](https://policies.google.com/terms/generative-ai/use-policy) for details.

**Q: Can I use generated images commercially?**
> Yes, as long as you own the rights to the original product image you uploaded.

**Q: Which version should I use?**
> If you're a developer or want to customize the tool, use **Version 1**. If you just want to use it quickly, use **Version 2**.
